# cc-proxy WebUI 设计（消纳自 anthropics/skills frontend-design）

本 skill 只服务一个对象：`crates/ccproxy/webui/` 的运维控制面板（原生 HTML/CSS/JS，build.rs 内联）。它是**信息密集型工具界面**，不是展示页——审美原则与 landing page 相反，以下内容已经过本地化裁剪。

## 适用边界

- 用：概览/明细/日志视图的视觉与交互优化；图表可读性；状态色语义；密度与节奏；响应式。
- 不用：品牌海报、营销视觉、动画秀、艺术化排版、无信息量的装饰。
- 本 skill 从 frontend-design 抽取了**设计思维 + 字体/配色/密度原则 + 避免 AI slop 清单**，丢弃了其 BOLD 营销审美。

## 控制面板设计三问（动手前）

1. **这张屏上用户做哪件事？**（概览=扫一眼健康度；明细=定位问题；日志=跟踪事件流）
2. **最重要的信息是什么？**（概览：缓存命中率/费用/内存；明细：状态与延迟；日志：错误与重试）
3. **什么会误导用户？**（状态色混淆、数字单位不清、图表刻度失真、过时数据未标注）

## 设计原则（对 webui 的本地化应用）

### 字体与数字

- **数字一律等宽**（`font-variant-numeric: tabular-nums`），让 token/延迟/费用列对齐可读——这是控制面板最重要的字体决策。**现状缺口已确认**：`tokens.css` 的 body 字体栈未设 `font-variant-numeric`，表格数字列是比例数字——优化时在 `tokens.css` 加一个 `--num` 工具类或直接设于 `body`。
- 中英混排字体栈保持现状（`-apple-system, "Segoe UI", "Microsoft YaHei", system-ui` 系统栈即可），**不要引入 Inter/Arial 等通用西文**，也不要为控制面板引入装饰字体。
- 字号层级：指标卡数值 > 面板标题 > 表格正文 > 辅助说明，层级差 ≥2px。

### 配色与状态语义

- 颜色只承载语义，不承载装饰：`ok/error/aborted/interrupted` 四种请求状态色已在 `tokens.css` 定义（`--ok: #81C995 / --error: #F28B82 / --aborted: #FDD663 / --interrupted: #8AB4F8`），为可区分色板，保持语义、不挪作装饰。
- 只在 `tokens.css` 的 CSS 变量体系内扩展，禁止硬编码色值——**项目已有测试强制**（`webui_site.rs` 有测试拒绝面板内的裸色值），改动后需通过该测试。
- 主色 + 单一强调色（`--primary-container #1E3A5F` + `--primary #8AB4F8` 方向正确）；强调色只用于「当前活跃/需要注意」元素。

### 密度与布局

- 表格是核心载体：行高、列宽、空态、分页的节奏优先；**不要**为了美观压缩表格行高。
- 负空间用于分组（指标卡组、面板组），不用来稀释信息。
- 状态条/环形图/趋势图：图例永远可见，坐标轴单位标注，交互 tooltip 补充细节而非承载必要信息。

### 图表可读性（现有 SVG 手绘图）

- 趋势图：网格线弱化、数据线强化；时间轴刻度采样（不要每点都标）；范围切换（7/14/30 天）保持当前图状态。
- 环形图：扇区按值降序；过小扇区合入「其他」并在 tooltip 给明细。
- 状态分布：条状图 + 数值标注，颜色与状态语义一致。

### 交互反馈

- 刷新/过滤/切换视图要有即时反馈（加载态、空态、错误态三分）。
- 日志自动滚动：跟随模式要有明确开关与视觉状态（现状已有，保持）。
- 数据为「本机实时」时标注时间戳；陈旧数据要有「N 秒前」之类的暗示。

## 优化清单（按页面）

### 概览（#/stats）
- 指标卡：数值 + 单位 + 短标签；缓存命中率卡要同时给「本次/累计」口径，避免与「掉缓存」诊断混淆。
- Token 趋势：Y 轴单位统一（K/M），范围切换高亮当前项。

### 明细（#/attempts）
- 过滤器（模型/流式/状态）保留选择状态（刷新不重置）；重置按钮语义明确。
- 表格列对齐：TOKEN/延迟列等宽数字；「尝试」列显示重试链（billing 的 attempt 语义）。
- 分页与过滤联动，空态文案具体（"没有符合条件的记录"）。

### 日志（#/logs）
- 代理日志高亮：错误行（ERROR）着色、重试行（retry）标注，级别过滤。
- 跟随模式 + 手动滚动互斥（用户滚动即暂停跟随，回底恢复）。

## 避免 AI slop 清单（本面板专属）

- 不用紫色渐变背景、不用圆角卡片堆叠、不用无意义动画。
- 不用 emoji 当状态图标（用现有 SVG 或语义色点）。
- 不为空态/面板添加营销文案。
- 所有改动保持 `tokens.css` 变量驱动，避免散落魔法值。

## 验证

- 改动后打开 webui 三个视图，检查：窄屏不破版、表格列不错位、图表图例可读、状态色可区分。
- 数据口径与后端 JSON API（`/api/...`）一致，不做前端造假值。

## 1. 方向一：tray 双击行为（A 组拍板）

### 1.1 决策
- **Windows**：双击 tray 图标 → 弹出 WebUI（现状为打开日志文件，改之）。单击维持无动作。
- **Linux**：SNI 规范无双击事件 → 单击/双击均无动作；弹 WebUI 只靠菜单「打开 WebUI」。跨平台语义统一。
- **菜单保留**「打开代理日志」「打开托盘日志」两项（仍有价值，不移除）。"日志文件淡出用户视野"仅指双击不再直接打开日志文件。

### 1.2 实现点
- `tray.rs`（Windows）：`WM_LBUTTONDBLCLK` → `Action::OpenWebUi`（替换 `OpenLog`）。
- 确认 `Action::OpenWebUi` 已存在且有跨平台实现（Windows/Linux 均打开 webui URL）；Linux 侧无改动（activate 不接）。
- 测试：Windows 双击消息映射单测（事件→Action 断言）+ 菜单仍含两个日志项。

## 2. 方向二：WebUI 大改（B 组 + R 组拍板）

### 2.1 总体定位
webui = **用户界面，看统计数据**，不是开发者调试工具。成本是核心价值。

### 2.2 时段选择器（B3、R1）
- **概览页**：默认展示 **24h**；new-api 风格时段选取器：预设快捷档（近 1h / 6h / 24h / 7d / 30d）+ 自定义分钟级起止。
- **明细页**：独立时段选取器，**与概览不共享选择器状态**（各自独立记忆）。
- 后端统计接口支持 `from`/`to`（ISO 时间）窗口参数；所有指标卡/图表按窗口重算；趋势图 x 轴=窗口，采样粒度自适应（≤24h 按小时点，跨天按天点）。

### 2.3 概览页
- **指标卡**（窗口口径重算）：
  - 保留/新增：请求数、Token（输入含缓存/输出）、**费用（今日/窗口内，成本最重要，突出展示）**、缓存命中率、总尝试（次口径）
  - 删除：成功率卡（价值低）、平均响应/平均首字（debug 向，从概览移除）
  - 系统统计（内存/运行时间/版本/连接状态）**保留顶栏**，不混入概览（B6、R2）。
- **趋势图**：保留多线趋势（输入/缓存/输出/命中率）+ **新增费用线**（B6）。
- **模型分布**：保留但 **列表限高**（滚动，不再把界面顶高）（B4）。
- 状态分布：保留，interrupted 等低频项按需合并。

### 2.4 明细页
- **按请求分组**（R6 拍板）：一行 = 一个客户端请求（按 reqId 聚合尝试）；同一请求的多行 attempt 合并为一行；有重试的行显示 `N 次尝试`。
- **统计口径切到请求**：成功率 = 请求最终成功（最后一次尝试 ok）；费用/缓存率按请求聚合；`总尝试` 保留为次口径指标。
- **TOKEN 列**（R3 拍板）：
  - 上一行：`↓输入 X（未缓存净输入）· ↑输出 W`
  - 下一行：`命中 Y（Z%）`（缓存读取及命中率）
  - **不显示缓存创建**（太小众，R3 拍板砍掉）
- **费用列**（R4 拍板）：表格显示**总耗费（USD）**（现算，按模型×峰谷价）；公式细节进侧栏。
- **时段框**：明细页顶部独立时段选取器（R1：与概览不共用状态）。
- **请求 ID**（新需求拍板）：只显示**前 6 位**，不完整展示；点击行 → 右侧滑出**详情侧栏**（不丢列表位置，加回归测试）。
- **errorTag**（R5-2 拍板）：并入状态 badge（`error · 429`，悬停看完整 tag）。
- 列集：`# / 请求ID(6位) / 模型 / 端点 / 类型 / 状态(+errorTag) / TOKEN(两行) / 费用 / 延迟 / 时间 / 尝试(N次)`。筛选保留（模型/类型/状态）。

### 2.5 详情侧栏（R7 拍板）
点击明细行右侧滑出抽屉，内容：
- 完整 reqId、时间、模型、端点、状态 + errorTag（完整）
- 各 token 数（输入净/命中/输出/推理）
- 延迟（首字/总耗时）
- **尝试链**：`#1 error 429 → #2 ok`（该请求全部 attempt 及各自状态）
- **费用公式分项**（R4/R5 拍板）：`未缓存输入 X × $a/M + 命中 Y × $b/M + 缓存创建 C × $c/M + 输出 W × $d/M = $总额`（按请求时刻峰谷价，展示每一部分金额）
- **工具列表**（R7 拍板，数据源见 2.6）
- 关闭后列表位置不丢（scroll 位置保持，加测试）

### 2.6 后端支撑
- **billing 加 `tools` 列**（R7-2 拍板）：JSON 数组存请求工具名列表；SCHEMA version bump + migration（ALTER TABLE 兼容既有库）；重试行冗余可忽略（每行都存）。
- **请求聚合 API**：`attempts` 查询支持 `from/to` 窗口 + 按 reqId 分组聚合（服务端聚合，避免前端聚合大表）。
- **费用分项 API**：`pricing::cost` 增加分项返回（或新 `cost_breakdown`），按行 ts 判定峰谷价（保持"历史行按当时价"语义，不重述）。

## 3. 方向三：日志优化（C/D 组 + R 组拍板）

### 3.1 分块存储（D8、D9）
- **按大小 FIFO 轮转**：proxy.log 超过阈值（默认 10MB）→ 滚动为新文件，保留 N 份（默认 3），最旧删除。tray.log 同策略（阈值可小些，如 1MB×3）。
- 路径/命名：`proxy.log` → `proxy.log.1/.2/.3`（FIFO 移位）或时间戳后缀——实现选 FIFO 移位（文件数固定，webui 只读当前块）。
- **webui 不翻旧日志**（D9）：只展示当前块；历史在文件系统查看（webui 定位=系统状态，非开发者工具 C7）。

### 3.2 WebUI 日志屏
- **DOM 裁剪**（D10）：跟随模式行数上限（默认 2000 行），超出裁剪头部（保留滚动位置语义）。
- **级别过滤**（R10 拍板）：多选复选框 ERROR/WARN/INFO/DEBUG（默认全选或默认 INFO+ 之上，按实现决定；配合降噪后按需看 DEBUG）。
- 增量轮询与自动滚动保留（已有）。
- 选框（proxy/tray）保留（已有，维持现状）。

### 3.3 proxy 日志降噪（D11、R9 拍板）
- 每请求日志从 3 行 → **1 行 INFO**：`[req] Model: X · Tools: N`（合并 Model + Tools count）。
- **Tools list 降 DEBUG**（大量重复信息，展示用处不大）。
- `[usage]` 累计行、错误/warn 行保留 INFO 级。
- 现状代码点：`server.rs::log_incoming_request`（Model / Tools count / Tools list 三行）→ 合并。

### 3.4 tray 日志细化分层（D12、R12 拍板）
级别分配原则：**越频繁、bug 可能性越小 → 越深的级别**。
- `[menu]` 菜单动作+结果（高频、低 bug 可能）→ **DEBUG**
- `[state]` 状态变化（启停/autostart 切换，中频、有 bug 可能）→ **INFO**
- `[sys]` DBus 注册/反注册、单实例冲突、启动失败（低频、bug 可能大）→ **INFO/WARN/ERROR**（失败类 WARN/ERROR）
- 全量事件覆盖：菜单动作结果（启停返回码/失败原因）、状态变化、webui 打开目标、autostart 切换详情、DBus 事件、单实例冲突。

### 3.5 缓存率标签接线（R13 拍板）
- tray 菜单两个缓存率标签（当前"—"占位）→ 接线 24h 缓存率（ledger 统计，复用 B3 时段统计能力）。
- 刷新策略：与菜单打开/轮询联动（实现时定，低频刷新即可）。

## 4. 会话维度（R8 拍板：本次不做，后置）

### 4.1 结论
- 上游缓存 = 输入前缀匹配（token 级），**不需要会话 ID**；threadId 仅用于 CC 计费会话。
- dsh 不传会话标识（实证：request/header 无 HTTP 头、request/context 无会话字段）；代理软件**不与客户端深耦合**（不装 dsh 插件、不自造回传协议）。
- 按会话区分缓存率为分析视角，非功能缺口；时段选择器 + 按请求分组 + 前缀 diff 已覆盖掉缓存排查诉求。

### 4.2 后置记录（v0.8 候选）
- 若客户端生态默认携带标准会话头（如 `x-session-id`），proxy 侧纯增量接住：billing 加 `sessionId` 列（migration）+ server.rs 读 header + webui 会话聚合接口。
- 本 feat 不引入该列（避免未接线字段）。

## 5. 状态机语义（R6 定稿，写入 UI 与文档）

```
客户端请求
  └→ attempt 1 ──┬─ ok（成功，结束）
                 ├─ aborted（客户端断开，结束）
                 ├─ error ──┬─ 可重试（5xx/429/model-discovery）→ attempt 2 → …
                 │           └─ 不可重试（auth/参数）→ 结束
                 └─ interrupted（流中断）→ splice 续流 → attempt 2（同一 threadId，不重复计费）
```
- 账本一行 = 一次上游尝试；`attempt` 1-based，>1=重试；同一 threadId 钉住（CC 计费会话不分裂）。
- 明细页呈现：按请求分组 + 侧栏尝试链（见 2.4/2.5）。

## 6. 质量门（沿用既有纪律）
- 隔离实例验证（`PORT=18787` + 独立数据目录）；生产只读不碰。
- `cargo test --workspace` 全绿；clippy `-D warnings`；fmt；doc `-D warnings`。
- 新增测试：双击映射单测、日志轮转单测、明细分组/侧栏滚动位置回归、级别过滤、费用分项快照。

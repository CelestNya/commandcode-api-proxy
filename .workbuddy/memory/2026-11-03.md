## 冰态果冻主题按 Auroraqua-UI 实况复刻

**背景**：此前的果冻主题是凭印象抄的（粉阴影、0.45 白玻璃、暖黑文字），
用户要求"拿其仓库代码的截图做对比，样式一模一样"。

**做法**：克隆 gitee `Fe5O6/Auroraqua-UI`（GitHub 附件不通，gitee 可达）到
`.probe/ref/`（已 gitignore），`npm install` + `npx vite --port 5199` 跑起，
用无头浏览器截真实渲染 + 提取 computed style + 采样像素，三重对照。

**六项关键修正**（此前的偏差全在这几处）：
1. 阴影色：粉 → **靛蓝紫 rgba(31,38,135,.20)**。这是"看着不像"的主因——
   粉阴影在粉底上化不开，靛蓝阴影才压得住粉紫底。
2. 玻璃：0.45 白 → **liquid-glass 的 0.15 白**，blur 20→24px、saturate 140→150%。
3. 文字：暖黑 #33202B → **靛蓝系 #312E81 / #5855E8**（实测两图笔画色簇完全相同）。
4. 背景：改 **135° 线性渐层 + 三团固定 px 径向光斑**。
5. 控件：按钮/输入框补参考的 blur(8px)。
6. 激活导航：pink-400 上白字仅 2.65:1 → 改 #CE2266→#B8185A。

**坑：径向渐变默认尺寸是 farthest-corner**——不写死 px，一颗 500px 的圆会
拉成覆盖整个视口的大团，把底色染成一片粉（这就是第一版"整体偏粉"的原因）。

**两处有意偏差**（理由已写进 theme-jelly.css 注释）：
- 主色 #ec4899 在粉底仅 3.00:1（参考靠大色块承载），压到同色相 #C41E62（4.77:1）。
- 参考的 `liquid-glass-glow` / `pulse-glow` 粉色外发光不启用（数据面板不该有
  呼吸光）。材质本身完全一致。

**实测结果**：像素对照 Δ1~13；整体色调 参考 rgb(245,223,230) 饱和 .105 vs
我们 rgb(248,226,233) 饱和 .099；文字对比度 参考 9.99 vs 我们 10.05；
关键文字 4.83~10.19、图表 4.62~4.77、激活导航白字 4.86（AA 达标）。

## 探针基础设施修复

- **Playwright 升级换版本号**：所有探针的 Chromium 路径 `chromium_headless_shell-1243`
  → `-1248`。路径写死是隐患，改成自动探测更好。
- **模板字符串里的正则**：探针里写 `/rgba?\(([^)]+)\)/` 放进 JS 模板字符串后
  `\(` 被吃掉成 `(`，正则废掉导致对比度算出 NaN。改用 `indexOf("(")` 手工截取。
- **主题参数位置**：`?theme=jelly` 放在 hash 之后（`#/stats?theme=jelly`）时
  `location.search` 读不到——必须在 hash 之前（`?theme=jelly#/stats`）。
- **linear-gradient 的 computed style**：解析不出色标（`parseFloat("135deg")`=135），
  渐变底色的对比度要用像素采样测，不能靠 computed style。

## 暗夜果冻（`jelly-dark`）+ 卡面/浮层两处修复

### 为什么选「暗夜粉紫」而不是参考仓库的 midnight
参考仓库 6 套方案里只有 `midnight` 标 `isDark`，但它是深蓝底，和果冻的粉紫/靛蓝不是一族。
定规则：**色相(H)守恒，只翻亮度/不透明度**——hue 变了就是另一个主题，没变就是同一主题的暗档。
按这张表落的 `theme-jelly-dark.css`：背景粉紫→深梅紫、玻璃配方逐字相同只降 alpha、
阴影同 hue `31,38,135` 只加浓度、文字靛蓝翻亮端、主色玫红提亮。结构轮廓与浅档像素同源。

### 卡面"位移/层级错误"其实是视觉错觉
用户报"卡片位移 + 前后层级错误"。探针读盒模型：6 张卡全部 `y=71`、同高 122、x 均匀、
`static/auto/none`、重叠检测为空 —— DOM 层零问题。
真因是**卡面太透**：暗档 `--surface` 只有 6% 白，遮不住背景三团亮色光斑，光斑从卡面
透出形成亮斑，配 45% 靛蓝大模糊阴影 → 看起来像卡后压了一层。
修：`--surface` 改深梅紫 `rgba(36,27,60,.72)`（白 alpha 再高也压不住光斑，必须换实色底）、
阴影收窄 32→28px、tooltip 单独给 `rgba(30,22,52,.97)`。

### 趋势浮层偏移：backdrop-filter 会创建 fixed 包含块（重要坑）
现象：悬停明细出现在鼠标**右下角很远**的地方。
根因：`.trend-tip` 是 `position:fixed`，但果冻主题的 `.panel` 带
`backdrop-filter: blur(24px) saturate(1.5)` —— **`backdrop-filter` 会给 fixed 后代创建
包含块**，于是 `left/top` 被当成「面板内坐标」，偏出正好一个面板原点。
实测：jelly / jelly-dark Δ(265,206) = 面板 rect(264,205)；基线 dark（panel 无 filter）Δ(0,0)。
⇒ **凡是给容器加 `backdrop-filter`/`filter`/`transform`，里面的 fixed 浮层就会错位。**
修：浮层移出 `.shell` 到 body 直属层；z-index 30→45（侧栏 40、抽屉 50 之间）；
定位改「贴光标右侧 + 垂直居中」并三向内收边（浮层 146px 高，比绘图区还高，原来悬在
光标上方会盖住面板标题）；脱离面板后切视图不再被一起藏住 → 抽出 `hideTrendTip()` 由
`router.js` 的 `route()` 显式调用。
